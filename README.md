# Lemonad Card: открытая информация о проекте

Базовая информация для закупки рекламы: продукт, аудитория, конкуренты, каналы, опубликованные статьи. Только открытые данные: сайт lemonadcard.com и исследования по открытым источникам.

## Продукт

Lemonad Card (lemonadcard.com) — виртуальные карты для оплаты рекламы и сервисов. Для арбитражников, медиабайеров и команд, которые оплачивают рекламные кабинеты (Facebook, Google, TikTok), трекеры, хостинг, нейросети и другие зарубежные сервисы. Сделан командой CPA-сети Limonad (LemonAD).

Условия с сайта (lemonadcard.com/ru/pricing/, проверено 06.11.2026):

- комиссия за пополнение 2,5% через Limonad, до 3% с криптовалюты;
- 20+ бесплатных карт, дальше $2 за карту;
- пополнение от $100;
- штраф $0,5 за отклонённую операцию, если доля отказов выше 15%;
- БИНы: Эстония и Сингапур (USD), готовятся США и Австралия;
- работа командой: роли, лимиты, общий и личный баланс, API.

Сайт: lemonadcard.com/ru/ · тарифы: lemonadcard.com/ru/pricing/ · FAQ: lemonadcard.com/ru/faq/ · Telegram: t.me/lemonadcard

## Аудитория

- Арбитражники и медиабайеры (соло и команды), которые льют трафик с Facebook, Google, TikTok.
- Таргетологи, маркетологи, специалисты по трафику.
- ИИ-креаторы и онлайн-бизнес, которым нужно оплачивать зарубежные сервисы и нейросети.

Какая это аудитория, что для неё важно, словарь ниши: `research/audience-arbitrazhniki.txt`.
